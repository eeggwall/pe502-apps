A castle of width w and height h is a row of w columns of unit cells on a common base, with column heights c = (c1, …, cw), each between 1 and h, and at least one column of height h. A block is a maximal horizontal run of filled cells in one row, and a castle may have an even or an odd number of blocks. This console is a companion to technical report PE502-1, Castle Polyominoes and How to Count Them, which counts all castles, A(w, h), and the even-block castles, Ae(w, h). Ae(w, h) is the F(w, h) of Project Euler Problem 502, whose castles are the even-block castles.
